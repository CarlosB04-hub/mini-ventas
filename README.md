# Mini sistema de ventas

Programa de consola en Python que permite registrar productos, controlar el stock y registrar ventas. Es un proyecto académico de práctica, una versión simplificada de un sistema de ventas, compras y producción.

## Qué hace
- Agregar productos con precio y stock
- Ver el listado de productos y el stock disponible
- Registrar ventas (descuenta el stock automáticamente)
- Ver el historial de ventas y el total vendido

## Tecnologías
- Python 3
- SQLite (base de datos incluida en Python, no requiere instalar nada)

## Cómo ejecutarlo
1. Tener Python 3 instalado.
2. Descargar `main.py`.
3. Abrir una terminal en la carpeta y ejecutar:

```
python main.py
```

Los datos se guardan en el archivo `ventas.db`, que se crea solo la primera vez.
